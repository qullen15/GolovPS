# VFS-Shell

Эмулятор командной строки UNIX-подобной ОС (VFS Shell Emulator).

## Общее описание

VFS-Shell имитирует работу в командной строке UNIX-подобной ОС:
приложение реализовано в форме CLI, читает команды пользователя
из терминала и выводит результат их выполнения.

Приглашение ко вводу формируется на основе реальных данных ОС —
имени пользователя и имени компьютера, например: `ivan@ivan-pc:~$`.

Текущий статус: завершены этапы 1 и 2 (REPL-прототип и конфигурация).

## Описание функций и настроек

### Параметры командной строки

| Параметр | Назначение | По умолчанию |
| --- | --- | --- |
| `--vfs PATH` | путь к физическому расположению VFS | не задан |
| `--script PATH` | путь к стартовому скрипту с командами эмулятора | не задан |
| `-h`, `--help` | справка по параметрам командной строки | — |

При запуске эмулятор печатает отладочный вывод всех заданных
параметров (строки с префиксом `[debug]`).

### Команды эмулятора

| Команда | Аргументы | Описание |
| --- | --- | --- |
| `ls` | необязательные | заглушка: выводит имя команды и аргументы |
| `cd` | необязательные | заглушка: выводит имя команды и аргументы |
| `exit` | нет | завершает работу эмулятора |

Любая неизвестная команда выводит сообщение об ошибке:
`<имя>: команда не найдена`.

### Парсер ввода

Ввод разделяется на команду и аргументы по пробелам.
Пустой ввод игнорируется.

### Стартовый скрипт

Стартовый скрипт — текстовый файл с командами эмулятора, по одной
на строку. При выполнении на экране отображаются и ввод, и вывод,
имитируя диалог с пользователем. При первой ошибке выполнение
скрипта останавливается, выводится сообщение об ошибке, эмулятор
завершается с кодом 1; при успешном выполнении код завершения 0.
Команда `exit` внутри скрипта завершает выполнение штатно.

## Сборка и запуск тестов

Сборка не требуется: проект написан на Python и запускается без компиляции.

Запуск эмулятора (из корня репозитория):

- Linux / macOS: `./run.sh` или `python3 src/main.py`
- Windows: `run.bat` или `py src/main.py`

Пример запуска с параметрами:

```bash
py src/main.py --vfs data/vfs.img --script scripts/demo.start
```

Запуск тестов (из корня репозитория):

- Linux / macOS: `python3 -m pytest tests/ -v`
- Windows: `py -m pytest tests/ -v`

Проверка параметров командной строки скриптами реальной ОС (Windows):

```bat
./check_params.bat
./check_errors.bat
```

## Примеры использования

Интерактивный режим:

```text
ivan@ivan-pc:~$ ls -l /home
Команда: ls, аргументы: -l /home
ivan@ivan-pc:~$ ping pong
ping: команда не найдена
ivan@ivan-pc:~$ exit
```

Режим стартового скрипта (в скрипте есть ошибочная команда):

```text
[debug] путь к VFS: не задан
[debug] путь к стартовому скрипту: scripts/error.start
ivan@ivan-pc:~$ ls -l
Команда: ls, аргументы: -l
ivan@ivan-pc:~$ ping pong
ping: команда не найдена
Ошибка выполнения стартового скрипта: работа остановлена
```
