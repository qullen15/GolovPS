# VFS-Shell

Эмулятор командной строки UNIX-подобной ОС (VFS Shell Emulator).

## Общее описание

VFS-Shell имитирует работу в командной строке UNIX-подобной ОС:
приложение реализовано в форме CLI, читает команды пользователя
из терминала и выводит результат их выполнения.

Приглашение ко вводу формируется на основе реальных данных ОС —
имени пользователя и имени компьютера, например: `ivan@ivan-pc:~$`.

## Описание функций и настроек

### Команды

| Команда | Аргументы   | Описание                                      |
| ------- | ----------- | --------------------------------------------- |
| `ls`    | необязательные | заглушка: выводит имя команды и аргументы |
| `cd`    | необязательные | заглушка: выводит имя команды и аргументы |
| `exit`  | нет         | завершает работу эмулятора                    |

Любая неизвестная команда выводит сообщение об ошибке:
`<имя>: команда не найдена`.

### Парсер ввода

Ввод разделяется на команду и аргументы по пробелам.
Пустой ввод игнорируется.

### Настройки

Параметры конфигурации на текущем этапе отсутствуют.

## Сборка и запуск тестов

Сборка не требуется: проект написан на Python и запускается без компиляции.

Запуск эмулятора (из корня репозитория):

- Linux / macOS: `./run.sh` или `python3 src/main.py`
- Windows: `run.bat` или `py src/main.py`

Запуск тестов (из корня репозитория):

- Linux / macOS: `python3 -m unittest discover -s tests -v`
- Windows: `py -m unittest discover -s tests -v`

## Примеры использования

Интерактивный режим:

```text
ivan@ivan-pc:~$ ls -l /home
Команда: ls, аргументы: -l /home
ivan@ivan-pc:~$ cd docs
Команда: cd, аргументы: docs
ivan@ivan-pc:~$ ping pong
ping: команда не найдена
ivan@ivan-pc:~$ exit
```
